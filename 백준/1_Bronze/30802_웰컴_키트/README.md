# [30802. 웰컴 키트](https://www.acmicpc.net/problem/30802)
### 문제
* 참가자수 N
* 둘째줄 티셔츠 사이즈별 신청자의 수
* 셋째줄 정수티셔츠와 펜의 묶음수 T/P
* 티셔츠는 같은 사이즈의 T장 묶음으로 주문 가능하고 펜은 한 종류 P자루씩 주문하거나 한자루씩 주문 가능.
* 티셔츠는 남아도 되고 펜은 참가자 수만큼 준비되어야 함
* 티셔츠는 최소 몇묶음 주문해야 하고 펜은 최대 몇묶음 주문할 수 있는지, 한 자루씩 몇개 주문하는지 구하기

### 풀이 방법
* 사이즈별 T 몫(나머지 있으면 +1) 합
* P몪 / P나머지
